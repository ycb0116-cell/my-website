# AI 運動防護隨身助理 (Web Version)

這是一套為「運動防護隨身助理」量身打造的純前端網頁應用程式 (HTML/CSS/JS)。

## 🚨 避免「上傳了卻還是舊網頁」的解決方法
因為瀏覽器很聰明，會偷偷記住舊的網頁資料。請在上傳新檔案並等 GitHub 打勾✅後，用以下方式開啟網頁：
* **Windows 電腦**：在網頁上按 `Ctrl` + `F5` 強制重新載入。
* **Mac 電腦**：在網頁上按 `Cmd` + `Shift` + `R`。
* 或者打開瀏覽器的 **「無痕模式 / 隱私瀏覽」** 再貼上你的網址，保證看到的一定是最新版！

解壓縮後，請直接把 `index.html` 拖曳到 GitHub，**不要連資料夾一起拖**！
