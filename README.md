# AI 運動防護隨身助理 (Web Version)

這是一套為「運動防護隨身助理」量身打造的純前端網頁應用程式 (HTML/CSS/JS)。
非常適合直接部署在 GitHub Pages 上進行展示！

## 如何正確部署到 GitHub Pages？ (避免 404 錯誤)

1. 解壓縮檔案後，確認你看到了 `index.html` 這個檔案。
2. 進入你的 GitHub Repository 頁面。
3. 點擊 `Add file` -> `Upload files`。
4. ⚠️ **關鍵步驟：** 請直接把 `index.html` 拖進去，**不要把資料夾拖進去**。確保網頁上顯示的路徑是直接放在根目錄。
5. 點擊綠色的 `Commit changes` 儲存。
6. 前往 Settings -> Pages。
7. 在 Branch 選擇 `main` (或 master)。
8. **確保後面的資料夾設定是 `/ (root)`**。
9. 儲存，等個 2~3 分鐘重整網頁即可！
